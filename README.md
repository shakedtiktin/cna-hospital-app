# CNA Hospital App

A responsive hospital dashboard landing page for the fictional hospital named **CNA Hospital**.

## View the app

You can open `index.html` directly in your browser, or run a local server:

```bash
cd cna-hospital-app
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` – app layout
- `styles.css` – styles and responsive design
- `script.js` – small interactive behavior

## Project idea

This is a modern hospital interface with:

- hero section
- medical services
- doctor list
- appointments panel
- emergency call banner
- clean healthcare theme
